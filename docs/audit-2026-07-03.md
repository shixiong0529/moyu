## 已验证的良好行为（非 bug，存档）

- **XSS 已防护**：`chat.jsx` 的 `dangerouslySetInnerHTML` 输入均先经 `escapeHtml`；图片预览只匹配图片扩展名 URL。存入 `<script>` 实测被转义。
- **删除级联无孤儿**：删服务器/用户后 `server_members/channels/messages/reactions/pinned_messages/invites/channel_groups` 均 0 残留。
- **权限边界**：普通成员改不了他人消息、删不了服务器、进不了后台；非成员连不上频道 WebSocket（`forbidden` + 1008）。
